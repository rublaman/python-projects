## Local configuration and demo data

These projects are personal learning exercises. Supply service credentials using
environment variables or an untracked `config.cfg`; never commit real credentials.
The email exercises read an `[email]` section with `account`, `secret`, and an
optional `recipient` (defaults to the configured account).

`WorkoutTracking` uses `SHEETY_WORKOUTS_URL` and `SHEETY_AUTHORIZATION` (the full
Authorization header value). `FlightDealsStart` uses `SHEETY_FLIGHT_PRICES_URL`;
pass the API credential to `DataManager` at runtime. Other integrations declare
their environment variable names in their source files.

`PasswordManagerGUI/data.json` is created locally when an entry is saved and is
excluded from Git. The password manager stores entries in plaintext and is an
educational demo: use fictitious data only, not real account passwords.
